# 《战墙·重生》更新公告编写指南

## 版本与发布

- 按游戏版本整理公告，版本号使用 `主版本.次版本.修订号`，例如 `1.1.2`。同一版本只保留一份公告，开发期间的增补、平衡调整和紧急修复并入实际发布它们的版本。
- 每个版本只写相对上一发布版本新增、变化或修正的内容。未发布版本中反复调整过的机制，以发布时的最终行为为准。已发布条目中的事实错误可在原版本更正，后续版本的行为变化写入后续公告。
- 有玩家可感知的变更时再新增公告。策划中的功能等到实装后再写。性能优化可以写明受益场景，例如大量唤灵同时在场，具体提升幅度以实测为准。

## 游戏内实现

- 公告数据维护在 [UpdateNotices.kt](../src/main/kotlin/shina/wallwarRebirth/match/lobby/UpdateNotices.kt)。大厅终端的「更新公告」直接打开最新一版，标题采用「1.1.2 更新公告」格式，版本号后保留一个空格。
- `UpdateNotices.all` 按从旧到新排列。补写现有版本时编辑对应的 `UpdateNotice`，新增版本时追加在末尾。最新公告取列表最后一项，版本号来自 `UpdateNotice.version`。发布时核对 [gradle.properties](../gradle.properties) 中的 `mod_version`。
- 每个版本通过 `UpdateNotice.icon` 选用一个与其他版本不同的物品图标。优先选能代表本版主要内容的物品。同一图标显示在历史列表中，也显示在该版本每一页最上方正中。
- 一张主题卡片对应一个 `UpdateEntry`。`item` 是主题图标，`title` 是卡片名称，`lore` 的每个字符串是鼠标悬停时单独显示的一行。主题图标优先沿用对应面板或游戏内物品，例如城墙用石砖，特斯拉塔用避雷针，破坏手用经验瓶。
- 单版本每页显示36张主题卡片，超过时自动分页，底部箭头循环切换。「历次更新公告」单页列出最近36个版本，顺序从新到旧。

## 条目怎么写

- **按主题组织卡片。** 标题优先用具体对象名，例如「农田」「冠军」「晶核制导炮」。跨单位的共通规则可以单列「防御建筑与唤灵索敌」。同一事实只在最相关的卡片里写一次，城墙价格写进「城墙」，电塔生命值写进「特斯拉塔」。
- **先写结果，再写条件。** 新功能交代使用入口或触发方式。机制和平衡改动写清最终数值与适用条件，旧值能帮助比较时再补。修复写出可感知的问题或修复后的行为，若已有公开问题编号，可在行末附上。
- **把相关改动合并。** 同一对象的新增、调整和修复可以放在一张卡片里。修复条目直接写出现象或修正后的结果，已有公开编号时可在句末附上。编写草稿时可用「新增」「更改」「修复」整理未归入主题的内容，游戏内以实际主题作为卡片标题。
- **每行只讲一个要点。** 优先把关键条件和结果放在同一行，较复杂的例外拆到下一行。卡片通常以 1 至 4 行为宜，涉及多种触发条件时可以增加。原始字符串按纯文本显示，请用分行表达层次。
- **把玩家需要知道的边界写清。** 根据改动补充等级、适用队伍、攻击或生产间隔、价格、冷却、目标优先级和触发条件。涉及操作时用「左键」「右键」「主手」「副手」「蹲下」等游戏内用语。

## 用词与数值

- 正文使用简明的书面中文，通过「玩家」「己方」「敌方」明确所指。生物可用「它」或「其」指代。统一写「其他」。
- 名称以游戏内显示为准，例如「唤灵·唤魔者」「恼鬼」「掠夺者哨塔」「晶震装置」「特斯拉塔」。沿用游戏内的专有缩写，如「TNT」。其他确有必要的外文术语在首次出现时可随中文名附上原文。
- 有计数或强调意义时用阿拉伯数字，例如「第2页」「1只唤灵」「3名玩家」。普通叙述可用「一个」或「一种」。中文与数字、英文字母之间不加空格，例如「冷却90秒」「生命上限10点」「亡灵杀手II」。
- 用全角句号、逗号和顿号，物品、技能和按钮名称可用「」标明，游戏名称用书名号。指令在游戏内写作「/ww match」，保留指令内部的空格。Markdown稿中可以用行内代码标记指令。
- 百分比写作「20%」，倍数写作「2倍」，费用可写作「铜锭×12」。数值区间可写作「120至300格」，空间尺寸用「×」连接。多个等级的数值按等级从低到高写，例如「1至3级攻击间隔分别为3、2、1秒」。
- 区分生命上限与当前生命、饱食度与饱和度、攻击间隔与技能冷却、攻击范围与爆炸半径。数值涉及概率或返还时，写明计算基数及必要的取整规则。

## 条目示例

以下示例展示版本图标和两张主题卡片。

```kotlin
UpdateNotice(
    version = "1.1.2",
    icon = Items.GOLDEN_APPLE,
    entries = listOf(
        UpdateEntry(
            Items.IRON_SWORD,
            "防御建筑与唤灵索敌",
            listOf(
                "敌人进入隐身时解除主动锁定。",
                "唤灵仍可反击实际攻击它的隐身敌人。",
            ),
        ),
        UpdateEntry(
            Items.STONE_BRICKS,
            "城墙",
            listOf("购买及两次升级各需12个铜锭。"),
        ),
    ),
)
```

## 发布前核对

- 从当前玩法实现核对数值、单位、操作键、触发条件和例外。价格可对照商店与建筑图鉴，职业效果可对照技能说明与实际结算。
- 浏览目标版本和上一版本，确认归属正确，同一事实只出现一次，已过时的中间方案已从待发布条目中清理。
- 核对版本图标是否各不相同，历史列表和每页顶部中央是否一致。进大厅检查主题图标、标题、悬停说明和翻页。
